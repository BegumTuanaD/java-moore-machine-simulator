# Moore Machine Simulator

A Moore Machine Simulator developed using Java and Swing.

## About the Project

This project is a desktop application that allows users to create and simulate Moore machines. Users can define states, input symbols, output symbols, and state transitions through a graphical interface.

## Features

- Define the number of states.
- Add input and output symbols.
- Create state transition tables.
- Define output values for each state.
- Simulate Moore machines using user inputs.
- Display simulation results through a graphical interface.

## Technologies Used

- Java
- Java Swing
- NetBeans IDE

## How to Use

1. Run the application.
2. Enter the number of states.
3. Define input and output symbols.
4. Configure the transition and output tables.
5. Enter an input sequence.
6. Start the simulation and observe the results.
